## 0. The DP Mindset

### DP = Recursion + Memoization

If you can write the recursion, the rest follows. Always start with recursion.

The pipeline:
```
Step 1: Brute force recursion — solve the problem naively, identify what changes per call
Step 2: Identify overlapping subproblems — same (i, j, ...) state called multiple times?
Step 3: Memoize — add dp table, return cached value if already computed
Step 4: Convert to tabulation — fill dp table bottom-up
Step 5: Space optimize — reduce dp dimensions if you only need previous row/column
```

### How to identify DP problems

- "Count the number of ways to..."
- "Find the minimum/maximum..."
- "Can you achieve X?" (decision problem with overlapping states)
- The problem has **optimal substructure** (optimal solution built from optimal sub-solutions)
- The problem has **overlapping subproblems** (same sub-problem recurs)

### The two arrays in your codebase (Recursion/)

**power.cpp** — compute 2^n using recursion:
```cpp
int power(int n) {
    if (n == 0) return 1;
    return 2 * power(n - 1);
}
```
This is O(n) recursion with no overlapping subproblems — so no DP needed.

**exponent.cpp** — compute a^b using fast exponentiation:
```cpp
int power(int a, int b) {
    if (b == 0) return 1;
    int ans = power(a, b/2);
    if (b % 2 == 0) return ans * ans;
    else return a * ans * ans;
}
```
This is the binary exponentiation divide-and-conquer pattern. b/2 subproblems. O(log b) time. This demonstrates the key insight of DP: reuse computed values (`ans` is computed once, used twice).

### Memoization Template

```cpp
// Always initialize dp to -1 (means "not computed")
int dp[N][M];
memset(dp, -1, sizeof(dp));

int solve(int i, int j, ...) {
    // Base cases first
    if (base_condition) return base_value;

    // Check memo
    if (dp[i][j] != -1) return dp[i][j];

    // Compute and store
    int result = /* ... recursive calls ... */;
    return dp[i][j] = result;
}
```

**Why -1?** Because the answer is never -1 for most DP problems (counts, lengths, sums ≥ 0). If the answer can be -1 (or 0), use a different sentinel like `INT_MIN` or a `bool computed[N][M]` array.

## 1. 1D DP — Linear Problems

### 1.1 Climbing Stairs / Fibonacci

**Problem:** Reach step n, can take 1 or 2 steps. How many ways?

**Recursion:**
```
f(n) = f(n-1) + f(n-2)  // come from step n-1 or step n-2
f(0) = 1, f(1) = 1
```

**With memoization:**
```cpp
int dp[N];
memset(dp, -1, sizeof(dp));

int climb(int n) {
    if (n == 0 || n == 1) return 1;
    if (dp[n] != -1) return dp[n];
    return dp[n] = climb(n-1) + climb(n-2);
}
```

**Tabulation:**
```cpp
int dp[n+1];
dp[0] = 1; dp[1] = 1;
for (int i = 2; i <= n; i++)
    dp[i] = dp[i-1] + dp[i-2];
return dp[n];
```

**Space optimized:**
```cpp
int prev2 = 1, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
}
return prev1;
```

**Time:** O(n), **Space:** O(1)

### 1.2 Frog Jump (Variable steps, min cost)

**Problem:** Frog at stone 0, wants to reach stone n-1. From stone i, can jump to i+1 or i+2. Cost = |height[i] - height[j]|. Minimize total cost.

**Recursion:**
```
minCost(i) = min(
    |h[i] - h[i-1]| + minCost(i-1),   // came from i-1
    |h[i] - h[i-2]| + minCost(i-2)    // came from i-2
)
minCost(0) = 0
```

**Tabulation:**
```cpp
vector<int> dp(n, 0);
for (int i = 1; i < n; i++) {
    int oneStep = dp[i-1] + abs(h[i] - h[i-1]);
    int twoStep = (i >= 2) ? dp[i-2] + abs(h[i] - h[i-2]) : INT_MAX;
    dp[i] = min(oneStep, twoStep);
}
return dp[n-1];
```

**Key insight:** DP[i] = minimum cost to REACH stone i. Answer is dp[n-1].

**Generalization:** If frog can jump up to K steps:
```cpp
for (int i = 1; i < n; i++) {
    dp[i] = INT_MAX;
    for (int k = 1; k <= K && i-k >= 0; k++) {
        dp[i] = min(dp[i], dp[i-k] + abs(h[i] - h[i-k]));
    }
}
```
**Time:** O(n × K)

### 1.3 House Robber (Non-adjacent elements, max sum)

**Problem:** Array of houses with money. Can't rob adjacent houses. Maximize money.

**Recursion:**
```
maxRob(i) = max(
    arr[i] + maxRob(i-2),   // rob house i, skip i-1
    maxRob(i-1)              // skip house i
)
```

**Tabulation:**
```cpp
vector<int> dp(n);
dp[0] = arr[0];
dp[1] = max(arr[0], arr[1]);
for (int i = 2; i < n; i++)
    dp[i] = max(arr[i] + dp[i-2], dp[i-1]);
return dp[n-1];
```

**Space optimized:**
```cpp
int prev2 = arr[0];
int prev1 = max(arr[0], arr[1]);
for (int i = 2; i < n; i++) {
    int curr = max(arr[i] + prev2, prev1);
    prev2 = prev1;
    prev1 = curr;
}
return prev1;
```

## 2. Grid DP — 2D Paths

### 2.1 Unique Paths (Count paths in grid)

**Problem:** m×n grid, start top-left, end bottom-right. Only right or down moves. Count paths.

**Recursion:**
```
paths(i, j) = paths(i-1, j) + paths(i, j-1)
paths(0, j) = 1  // only one way along top row
paths(i, 0) = 1  // only one way along left column
```

**Tabulation:**
```cpp
vector<vector<int>> dp(m, vector<int>(n, 1));  // initialize to 1
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1];
return dp[m-1][n-1];
```

**Space optimized (1D):**
```cpp
vector<int> dp(n, 1);
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[j] += dp[j-1];
return dp[n-1];
```

**Time:** O(m×n), **Space:** O(n) after optimization

### 2.2 Minimum Path Sum

**Problem:** m×n grid with numbers, find path from top-left to bottom-right minimizing sum.

```cpp
vector<vector<int>> dp(m, vector<int>(n));
dp[0][0] = grid[0][0];

// Fill first row and column
for (int j = 1; j < n; j++) dp[0][j] = dp[0][j-1] + grid[0][j];
for (int i = 1; i < m; i++) dp[i][0] = dp[i-1][0] + grid[i][0];

// Fill rest
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]);

return dp[m-1][n-1];
```

### 2.3 Triangle (Variable start, multiple paths)

**Problem:** Triangle array. Start at top, reach bottom. Can go to adjacent elements below. Minimize path sum.

**Bottom-up (easier direction):**
```cpp
// Copy last row as base
vector<int> dp = triangle.back();

// Fill from second-last row up
for (int i = triangle.size()-2; i >= 0; i--)
    for (int j = 0; j <= i; j++)
        dp[j] = triangle[i][j] + min(dp[j], dp[j+1]);

return dp[0];
```

**Key insight:** Going bottom-up is easier here because the last row has no "next row" dependency.

### 2.4 Chocolate Pickup (Two starting points, harder variant)

**Problem:** r×c grid. Two people start at row 0, different columns. Both move to row r-1. Maximize chocolates collected. If both on same cell, count once.

**State:** `dp[row][col1][col2]` — row determines automatically as both move together.

```cpp
// dp[i][j1][j2] = max chocolates when both at row i, person1 at col j1, person2 at col j2
int dp[r][c][c];
// Initialize dp[r-1][j1][j2]
// For each row from r-2 to 0, try all 9 combinations of (move1, move2) ∈ {-1,0,1} × {-1,0,1}
```

## 3. DP on Subsequences — Knapsack Family

### 3.1 0/1 Knapsack — the foundation

**Problem:** n items, each with weight `w[i]` and value `v[i]`. Knapsack capacity W. Maximize value. Each item used at most once.

**Recursion:**
```
f(i, W) = max(
    v[i] + f(i-1, W - w[i]),   // take item i (only if w[i] <= W)
    f(i-1, W)                   // skip item i
)
f(0, W) = 0  (no items left)
```

**Tabulation:**
```cpp
// dp[i][j] = max value using first i items with capacity j
vector<vector<int>> dp(n+1, vector<int>(W+1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i-1][j];  // skip item i
        if (w[i-1] <= j)
            dp[i][j] = max(dp[i][j], v[i-1] + dp[i-1][j - w[i-1]]);
    }
}
return dp[n][W];
```

**Space optimized (1D, process right to left):**
```cpp
vector<int> dp(W+1, 0);
for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {  // RIGHT TO LEFT — critical!
        dp[j] = max(dp[j], v[i] + dp[j - w[i]]);
    }
}
return dp[W];
```

**Why right to left for 0/1 knapsack?** When processing item i in-place, `dp[j - w[i]]` must be the value WITHOUT item i. If we go left to right, by the time we compute dp[j], dp[j-w[i]] might already include item i (counted twice). Going right to left ensures dp[j-w[i]] is still from the previous item.

### 3.2 Subset Sum — can we reach target?

**Problem:** Array of integers. Can we select a subset with sum = target?

```cpp
// dp[i][j] = true if sum j achievable using first i elements
vector<vector<bool>> dp(n+1, vector<bool>(target+1, false));
for (int i = 0; i <= n; i++) dp[i][0] = true;  // empty subset = sum 0

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= target; j++) {
        dp[i][j] = dp[i-1][j];  // don't take element i
        if (arr[i-1] <= j)
            dp[i][j] = dp[i][j] || dp[i-1][j - arr[i-1]];
    }
}
return dp[n][target];
```

**Space optimized:**
```cpp
vector<bool> dp(target+1, false);
dp[0] = true;
for (int i = 0; i < n; i++) {
    for (int j = target; j >= arr[i]; j--) {  // right to left
        dp[j] = dp[j] || dp[j - arr[i]];
    }
}
return dp[target];
```

### 3.3 Partition Equal Subset Sum

**Problem:** Can the array be partitioned into two subsets with equal sum?

```cpp
int total = sum(arr);
if (total % 2 != 0) return false;  // odd total — impossible
return subsetSum(arr, total / 2);  // find subset with sum = total/2
```

### 3.4 Count Subsets with Given Sum

```cpp
// dp[j] = number of ways to achieve sum j
vector<int> dp(target+1, 0);
dp[0] = 1;  // one way to make sum 0: empty subset
for (int i = 0; i < n; i++) {
    for (int j = target; j >= arr[i]; j--) {
        dp[j] += dp[j - arr[i]];  // count, not bool
    }
}
return dp[target];
```

### 3.5 Coin Change — Minimum coins (unbounded knapsack)

**Problem:** Coins of given denominations. Minimum coins to make amount. **Unlimited coins.**

**Key difference from 0/1 knapsack:** Each coin can be used unlimited times → iterate LEFT TO RIGHT (not right to left).

```cpp
// dp[j] = min coins to make amount j
vector<int> dp(amount+1, INT_MAX);
dp[0] = 0;

for (int coin : coins) {
    for (int j = coin; j <= amount; j++) {  // LEFT TO RIGHT — unlimited use!
        if (dp[j - coin] != INT_MAX)
            dp[j] = min(dp[j], dp[j - coin] + 1);
    }
}
return dp[amount] == INT_MAX ? -1 : dp[amount];
```

### 3.6 Coin Change II — Count ways (unbounded)

```cpp
// dp[j] = number of ways to make amount j
vector<long long> dp(amount+1, 0);
dp[0] = 1;

for (int coin : coins) {
    for (int j = coin; j <= amount; j++) {
        dp[j] += dp[j - coin];  // unbounded: left to right
    }
}
return dp[amount];
```

### 3.7 Rod Cutting (also unbounded knapsack)

```cpp
// price[i] = price of rod of length i+1
// dp[j] = max value for rod of length j
vector<int> dp(n+1, 0);
for (int i = 1; i <= n; i++) {     // each length
    for (int j = i; j <= n; j++) { // unbounded: left to right
        dp[j] = max(dp[j], price[i-1] + dp[j-i]);
    }
}
return dp[n];
```

### 0/1 vs Unbounded — the critical difference

| | 0/1 Knapsack | Unbounded Knapsack |
|--|-------------|-------------------|
| Each item | Used once | Used unlimited times |
| Loop direction | RIGHT to LEFT | LEFT to RIGHT |
| Why | Prevents double-counting | Allows reusing same item |
| Examples | Subset sum, partition | Coin change, rod cutting |

## 4. DP on Strings — LCS, Edit Distance

### 4.1 Longest Common Subsequence (LCS)

**Problem:** Find length of longest subsequence common to both strings.

**Recursion:**
```
lcs(i, j) =
    1 + lcs(i-1, j-1)              if s1[i] == s2[j]
    max(lcs(i-1, j), lcs(i, j-1)) otherwise
```

**Tabulation:**
```cpp
int n = s1.size(), m = s2.size();
vector<vector<int>> dp(n+1, vector<int>(m+1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (s1[i-1] == s2[j-1])
            dp[i][j] = 1 + dp[i-1][j-1];
        else
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
return dp[n][m];
```

**LCS applications:**
- **LCS length** = direct output
- **Longest Common Substring** = `dp[i][j] = 1 + dp[i-1][j-1]` if match, else 0
- **Shortest Common Supersequence length** = n + m - LCS(n, m)
- **Min insertions/deletions to convert s1 to s2** = n + m - 2×LCS
- **LIS** reduces to LCS(arr, sorted(arr))

### 4.2 Edit Distance (Levenshtein distance)

**Problem:** Minimum operations (insert, delete, replace) to convert s1 to s2.

**Recursion:**
```
edit(i, j) =
    edit(i-1, j-1)                         if s1[i] == s2[j]  // no op needed
    1 + min(
        edit(i-1, j),                       // delete from s1
        edit(i, j-1),                       // insert into s1
        edit(i-1, j-1)                      // replace in s1
    )                                       otherwise
```

**Tabulation:**
```cpp
vector<vector<int>> dp(n+1, vector<int>(m+1, 0));

// Base cases: convert prefix to empty string
for (int i = 0; i <= n; i++) dp[i][0] = i;  // delete all of s1
for (int j = 0; j <= m; j++) dp[0][j] = j;  // insert all of s2

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (s1[i-1] == s2[j-1])
            dp[i][j] = dp[i-1][j-1];
        else
            dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
    }
}
return dp[n][m];
```

**Base case explanation:** 
- `dp[i][0] = i` — to convert first i chars of s1 to empty string, delete all i chars
- `dp[0][j] = j` — to convert empty string to first j chars of s2, insert all j chars

### 4.3 Wildcard Matching

**Problem:** Pattern p with `*` (any sequence) and `?` (any single char). Does p match s?

```cpp
// dp[i][j] = true if p[0..i-1] matches s[0..j-1]
vector<vector<bool>> dp(m+1, vector<bool>(n+1, false));
dp[0][0] = true;  // empty pattern matches empty string

// Initialize: pattern of only '*' can match empty string
for (int i = 1; i <= m; i++)
    if (p[i-1] == '*') dp[i][0] = dp[i-1][0];

for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (p[i-1] == '*')
            dp[i][j] = dp[i-1][j] ||  // '*' matches zero chars
                       dp[i][j-1];    // '*' matches one more char
        else if (p[i-1] == '?' || p[i-1] == s[j-1])
            dp[i][j] = dp[i-1][j-1];  // single char match
        // else dp[i][j] = false (default)
    }
}
return dp[m][n];
```

### 4.4 Distinct Subsequences

**Problem:** Count distinct subsequences of s that equal t.

```cpp
vector<vector<long long>> dp(n+1, vector<long long>(m+1, 0));
for (int i = 0; i <= n; i++) dp[i][0] = 1;  // empty t is always matched

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        dp[i][j] = dp[i-1][j];  // don't use s[i] to match t[j]
        if (s[i-1] == t[j-1])
            dp[i][j] += dp[i-1][j-1];  // use s[i] to match t[j]
    }
}
return dp[n][m];
```

## 5. DP on Stocks — Buy & Sell Series

These 6 problems form a family. Know how the state changes.

### 5.1 Best Time to Buy and Sell Stock I (at most 1 transaction)

No DP needed — just track min so far:
```cpp
int minPrice = INT_MAX, maxProfit = 0;
for (int price : prices) {
    minPrice = min(minPrice, price);
    maxProfit = max(maxProfit, price - minPrice);
}
return maxProfit;
```

### 5.2 Best Time to Buy and Sell Stock II (unlimited transactions)

Sum all positive differences (greedy):
```cpp
int profit = 0;
for (int i = 1; i < n; i++)
    if (prices[i] > prices[i-1])
        profit += prices[i] - prices[i-1];
return profit;
```

### 5.3 Best Time to Buy and Sell Stock III (at most 2 transactions)

**State:** `dp[i][j][hold]`
- i = day
- j = number of transactions used (0, 1, 2)
- hold = 0 (not holding stock), 1 (holding stock)

```cpp
// Simplified: track 4 variables
int buy1 = INT_MIN, sell1 = 0, buy2 = INT_MIN, sell2 = 0;

for (int price : prices) {
    buy1  = max(buy1,  -price);           // max profit after 1st buy
    sell1 = max(sell1, buy1 + price);     // max profit after 1st sell
    buy2  = max(buy2,  sell1 - price);    // max profit after 2nd buy
    sell2 = max(sell2, buy2 + price);     // max profit after 2nd sell
}
return sell2;
```

### 5.4 Best Time to Buy and Sell Stock IV (at most k transactions)

```cpp
// dp[j][hold] where j = transactions used so far
vector<vector<int>> dp(k+1, vector<int>(2, 0));
for (int j = 0; j <= k; j++) dp[j][1] = INT_MIN;  // holding stock initially impossible

for (int price : prices) {
    for (int j = k; j >= 1; j--) {
        dp[j][0] = max(dp[j][0], dp[j][1] + price);  // sell
        dp[j][1] = max(dp[j][1], dp[j-1][0] - price); // buy
    }
}
return dp[k][0];
```

### 5.5 Best Time to Buy and Sell Stock with Cooldown

After selling, must wait 1 day before buying again.

```cpp
// State: held (holding stock), sold (just sold, in cooldown), rest (not holding, not cooldown)
int held = INT_MIN, sold = 0, rest = 0;

for (int price : prices) {
    int prevHeld = held, prevSold = sold, prevRest = rest;
    held = max(prevHeld, prevRest - price);  // buy only from rest state
    sold = prevHeld + price;                  // sell whatever we held
    rest = max(prevRest, prevSold);           // rest: from rest or after cooldown
}
return max(sold, rest);
```

### 5.6 Best Time to Buy and Sell Stock with Transaction Fee

```cpp
int hold = INT_MIN, cash = 0;
for (int price : prices) {
    hold = max(hold, cash - price);             // buy
    cash = max(cash, hold + price - fee);       // sell, pay fee
}
return cash;
```

### Stock problems pattern summary

| Problem | Key constraint | Approach |
|---------|---------------|----------|
| I | 1 transaction | Track min, max diff |
| II | Unlimited | Sum positive diffs |
| III | 2 transactions | 4 variables simulation |
| IV | k transactions | 2D DP on k |
| Cooldown | 1-day cooldown | 3 states: held/sold/rest |
| Fee | Fee per transaction | 2 states: hold/cash |

## 6. DP on LIS — Longest Increasing Subsequence

### 6.1 LIS — O(n²) DP approach

**Problem:** Find length of longest strictly increasing subsequence.

```cpp
vector<int> dp(n, 1);  // each element is LIS of length 1

for (int i = 1; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (arr[j] < arr[i]) {
            dp[i] = max(dp[i], dp[j] + 1);
        }
    }
}
return *max_element(dp.begin(), dp.end());
```

**Key insight:** `dp[i]` = length of LIS ending at index i. Answer = max over all dp[i].

### 6.2 LIS — O(n log n) patience sorting approach

```cpp
vector<int> tails;  // tails[i] = smallest tail element of IS with length i+1

for (int x : arr) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);  // x extends the longest IS
    else *it = x;  // x replaces an element — same length, but smaller tail
}
return tails.size();
```

**Why does this work?** `tails` is always sorted. We binary search for the leftmost tail ≥ x. If we replace it with x, the length stays the same but x is smaller (better tail for future extensions). If x is larger than all, it extends the LIS by 1.

**Note:** `tails` doesn't necessarily represent an actual LIS, just tracks lengths efficiently.

### 6.3 Number of LIS

```cpp
vector<int> len(n, 1), cnt(n, 1);

for (int i = 1; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (arr[j] < arr[i]) {
            if (len[j] + 1 > len[i]) {
                len[i] = len[j] + 1;
                cnt[i] = cnt[j];   // new best: reset count
            } else if (len[j] + 1 == len[i]) {
                cnt[i] += cnt[j];  // same length: add count
            }
        }
    }
}

int maxLen = *max_element(len.begin(), len.end());
int result = 0;
for (int i = 0; i < n; i++)
    if (len[i] == maxLen) result += cnt[i];
return result;
```

### 6.4 Russian Doll Envelopes (2D LIS)

**Problem:** Envelopes (w, h). One fits in another if both dimensions strictly smaller. Max nesting.

**Key insight:** Sort by width ascending, then height DESCENDING. Find LIS on heights.
Why descending height? If two envelopes have same width, we can't nest them. Sorting height descending ensures we never pick two same-width envelopes in the LIS.

```cpp
sort(envelopes.begin(), envelopes.end(), [](auto &a, auto &b) {
    return a[0] != b[0] ? a[0] < b[0] : a[1] > b[1];  // sort width asc, height DESC
});
// Then find LIS on heights using O(n log n) method
```

## 7. DP on Partitions — Matrix Chain, Burst Balloons

### 7.1 Matrix Chain Multiplication

**Problem:** Chain of matrices A1×A2×...×An. Order of multiplication matters (cost = dimensions). Minimize total multiplications.

**State:** `dp[i][j]` = min cost to multiply matrices i to j.

**Recursion:**
```
dp[i][j] = min over k from i to j-1:
    dp[i][k] + dp[k+1][j] + arr[i-1] * arr[k] * arr[j]
```

```cpp
int n = dims.size() - 1;  // number of matrices
vector<vector<int>> dp(n+1, vector<int>(n+1, 0));

// Fill by increasing chain length
for (int len = 2; len <= n; len++) {
    for (int i = 1; i <= n - len + 1; i++) {
        int j = i + len - 1;
        dp[i][j] = INT_MAX;
        for (int k = i; k < j; k++) {
            int cost = dp[i][k] + dp[k+1][j] + dims[i-1] * dims[k] * dims[j];
            dp[i][j] = min(dp[i][j], cost);
        }
    }
}
return dp[1][n];
```

**Template pattern for partition DP:** Fill dp by increasing interval lengths (outer loop = length, inner loops = start and split point).

**Time:** O(n³), **Space:** O(n²)

### 7.2 Burst Balloons

**Problem:** Row of balloons with numbers. Burst balloon i: gain `nums[i-1] * nums[i] * nums[i+1]`. After burst, i's neighbors become adjacent. Maximize total coins.

**The trick:** Instead of thinking "which balloon to burst first," think "which balloon to burst LAST in range [i,j]." The last balloon to burst in a range is guaranteed to have `nums[i-1]` and `nums[j+1]` as its neighbors (all others already gone).

```cpp
// Add sentinel 1s at both ends
vector<int> nums = {1};
for (int x : balloons) nums.push_back(x);
nums.push_back(1);

int n = nums.size();
vector<vector<int>> dp(n, vector<int>(n, 0));

for (int len = 2; len < n; len++) {
    for (int left = 0; left < n - len; left++) {
        int right = left + len;
        for (int k = left + 1; k < right; k++) {
            // k is the LAST balloon to burst in (left, right)
            dp[left][right] = max(dp[left][right],
                dp[left][k] + dp[k][right] + nums[left] * nums[k] * nums[right]);
        }
    }
}
return dp[0][n-1];
```

### 7.3 Palindrome Partitioning II (Min cuts)

**Problem:** Minimum cuts to partition string into palindromes.

```cpp
// First precompute isPalin[i][j]
vector<vector<bool>> isPalin(n, vector<bool>(n, false));
for (int i = n-1; i >= 0; i--) {
    for (int j = i; j < n; j++) {
        if (s[i] == s[j] && (j - i <= 2 || isPalin[i+1][j-1]))
            isPalin[i][j] = true;
    }
}

// dp[i] = min cuts for s[0..i]
vector<int> dp(n, INT_MAX);
for (int i = 0; i < n; i++) {
    if (isPalin[0][i]) { dp[i] = 0; continue; }  // whole prefix is palindrome
    for (int j = 1; j <= i; j++) {
        if (isPalin[j][i])
            dp[i] = min(dp[i], dp[j-1] + 1);
    }
}
return dp[n-1];
```

## 8. DP on Trees — Max Sum Independent Set

### Problem: Maximum sum non-adjacent nodes in tree

**State:** For each node, two choices:
- `dp[node][0]` = max sum in subtree if node is NOT selected
- `dp[node][1]` = max sum in subtree if node IS selected

**Recursion:**
```
dp[node][1] = val[node] + sum over children: dp[child][0]  // take node, skip children
dp[node][0] = sum over children: max(dp[child][0], dp[child][1])  // skip node, best of each child
```

```cpp
void dfs(int node, int parent, vector<int> adj[], vector<int> &val,
         vector<int> &dp0, vector<int> &dp1) {
    dp0[node] = 0;
    dp1[node] = val[node];

    for (int child : adj[node]) {
        if (child == parent) continue;
        dfs(child, node, adj, val, dp0, dp1);

        dp0[node] += max(dp0[child], dp1[child]);  // skip node: best of child
        dp1[node] += dp0[child];  // take node: child must be skipped
    }
}

// Answer = max(dp0[root], dp1[root])
```

### Diameter of Binary Tree

```cpp
int ans = 0;
int dfs(TreeNode* node) {
    if (!node) return 0;
    int left = dfs(node->left);
    int right = dfs(node->right);
    ans = max(ans, left + right);  // path through this node
    return 1 + max(left, right);   // height of this subtree
}
```

## 9. Bitmask DP

### When to use

If n ≤ 20 and the problem involves **trying all subsets of items/nodes** where the order or combination matters — bitmask DP.

**Pattern recognition:**
- "Visit all cities / nodes exactly once" → TSP
- "Assign n tasks to n workers optimally" → Assignment problem
- "Minimum cost to cover all elements" → Set cover
- State needs to track WHICH elements have been used → use a bitmask

**Constraint check:** `n ≤ 20` → `2^20 = 10^6` states (feasible). `n > 20` → bitmask DP will TLE.

### State definition

```
dp[mask][node] = optimal answer having visited exactly the nodes in `mask`,
                 currently at `node`
```

`mask` is a bitmask where bit `i` = 1 means city/node `i` has been visited.

### Travelling Salesman Problem (TSP) — visit all nodes with min cost

```cpp
// dist[i][j] = cost to travel from i to j
// Start at node 0, visit all n nodes, return to 0
// dp[mask][i] = min cost to reach node i having visited exactly nodes in mask

int tsp(int n, vector<vector<int>>& dist) {
    int FULL = (1 << n) - 1;  // all n bits set = all nodes visited
    vector<vector<int>> dp(1 << n, vector<int>(n, INT_MAX));
    dp[1][0] = 0;  // start at node 0, only node 0 visited (mask = 0b0001)

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int u = 0; u < n; u++) {
            if (!(mask & (1 << u))) continue;  // u not in current mask — skip
            if (dp[mask][u] == INT_MAX) continue;

            // Try going to each unvisited node v
            for (int v = 0; v < n; v++) {
                if (mask & (1 << v)) continue;  // v already visited
                int newMask = mask | (1 << v);
                dp[newMask][v] = min(dp[newMask][v], dp[mask][u] + dist[u][v]);
            }
        }
    }

    // Find minimum cost to return to node 0 from any node, having visited all
    int ans = INT_MAX;
    for (int u = 1; u < n; u++) {
        if (dp[FULL][u] != INT_MAX)
            ans = min(ans, dp[FULL][u] + dist[u][0]);
    }
    return ans;
}
// Time: O(2^n × n²)   Space: O(2^n × n)
```

**Trace for n=4, start at 0:**
```
mask = 0001 (only node 0): dp[0001][0] = 0
mask = 0011 (nodes 0,1):   dp[0011][1] = dp[0001][0] + dist[0][1]
mask = 0101 (nodes 0,2):   dp[0101][2] = dp[0001][0] + dist[0][2]
...
mask = 1111 (all visited):  dp[1111][u] = min cost to reach u visiting all
Answer: min over u of dp[1111][u] + dist[u][0]
```

### Assignment Problem (min cost to assign n tasks to n workers)

Same structure. `dp[mask][i]` = min cost to assign the first `popcount(mask)` tasks, where `mask` represents which workers have been assigned a task so far, and `i` is the index of the next task to assign.

```cpp
// cost[i][j] = cost of assigning task i to worker j
// dp[mask] = min cost to assign tasks 0..popcount(mask)-1
//            where mask indicates which workers are used

int assignTasks(int n, vector<vector<int>>& cost) {
    vector<int> dp(1 << n, INT_MAX);
    dp[0] = 0;

    for (int mask = 0; mask < (1 << n); mask++) {
        if (dp[mask] == INT_MAX) continue;
        int task = __builtin_popcount(mask);  // next task index = number already assigned
        if (task == n) continue;

        for (int worker = 0; worker < n; worker++) {
            if (mask & (1 << worker)) continue;  // worker already assigned
            dp[mask | (1 << worker)] = min(
                dp[mask | (1 << worker)],
                dp[mask] + cost[task][worker]
            );
        }
    }
    return dp[(1 << n) - 1];
}
// Time: O(2^n × n)   Space: O(2^n)
```

**Key insight:** `__builtin_popcount(mask)` = number of bits set = number of tasks already assigned = index of the NEXT task to assign. This maps each mask uniquely to a task, so no extra dimension needed.

### Minimum number of XOR covers (bitmask DP on subsets)

**Problem:** Given n numbers, find the minimum number of operations to "cover" all. Each operation covers a subset. Common in "minimum groups / partition" problems.

```cpp
// dp[mask] = min ops to cover exactly the elements in mask
vector<int> dp(1 << n, INT_MAX);
dp[0] = 0;

for (int mask = 1; mask < (1 << n); mask++) {
    // Try all subsets of mask as the "last operation"
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
        if (isValid(sub) && dp[mask ^ sub] != INT_MAX)
            dp[mask] = min(dp[mask], dp[mask ^ sub] + 1);
    }
}
return dp[(1 << n) - 1];

// Iterating all subsets of mask: O(3^n) total across all masks
// (each element is in: neither mask nor sub / only mask / both → 3 choices per element)
```

**Iterating all subsets of a mask — the standard trick:**
```cpp
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // process sub
    // when sub = 0, (0 - 1) & mask = mask again → infinite loop → condition sub > 0 stops it
}
// Include sub = 0 (empty subset) if needed:
for (int sub = mask; ; sub = (sub - 1) & mask) {
    // process sub
    if (sub == 0) break;
}
```

### Bitmask DP Template Summary

```
State:  dp[mask][i]  or  dp[mask]
Mask:   bit j = 1 means element j is "used/visited"
Init:   dp[1 << src][src] = 0  (start at source, only source visited)
        dp[0] = 0               (nothing assigned yet)
Trans:  for each valid next choice v not in mask:
            dp[mask | (1<<v)][v] = min(..., dp[mask][u] + cost[u][v])
Answer: dp[(1<<n)-1][...] — all bits set = all elements covered
```

### Things to remember for Bitmask DP

```cpp
// Check if bit i is set in mask
if (mask & (1 << i))

// Add node i to mask
int newMask = mask | (1 << i);

// Remove node i from mask
int newMask = mask & ~(1 << i);

// Count nodes in mask (number visited)
__builtin_popcount(mask)

// Full mask (all n nodes visited)
int FULL = (1 << n) - 1;

// Iterate all subsets of mask (excluding empty)
for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
```

## 10. Space Optimization Techniques

### 2D → 1D (most common)

When `dp[i][j]` depends only on `dp[i-1][...]` (previous row), you can use a 1D array and process carefully.

```cpp
// From 2D:
dp[i][j] = dp[i-1][j] + dp[i-1][j-w] + ...

// To 1D (right to left for 0/1 knapsack):
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)  // RIGHT TO LEFT
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

// For unbounded knapsack (left to right):
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= W; j++)  // LEFT TO RIGHT
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

### Two-row rolling array

When you need `dp[i-1]` explicitly:
```cpp
vector<int> prev(m+1, 0), curr(m+1, 0);
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        curr[j] = /* formula using prev[j], prev[j-1], curr[j-1] */;
    }
    swap(prev, curr);
}
return prev[m];
```

### When space optimization is NOT possible

- When you need to reconstruct the path (backtracking through dp table)
- When dp[i] depends on non-adjacent rows (e.g., dp[i-k] for variable k)
- Partition DP (matrix chain, burst balloons) — need full 2D table

## 10. Things Most People Forget

### 1. 0/1 knapsack 1D: right to left; unbounded: left to right

```cpp
// 0/1: each item once → right to left prevents re-use
for (int j = W; j >= w[i]; j--) dp[j] = max(dp[j], dp[j-w[i]] + v[i]);

// Unbounded: reuse allowed → left to right
for (int j = w[i]; j <= W; j++) dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
```

### 2. LIS dp[i] = length ending AT i (not anywhere before i)

```cpp
for (int i = 0; i < n; i++) dp[i] = 1;  // don't initialize to 0!
// Answer = max(dp), NOT dp[n-1]
```

### 3. Edit distance base cases

```cpp
dp[i][0] = i;  // delete i characters
dp[0][j] = j;  // insert j characters
```

### 4. Partition DP fills by interval length (outer loop = length)

```cpp
for (int len = 2; len <= n; len++)     // outer: interval length
    for (int i = 1; i <= n-len+1; i++) // inner: start
        for (int k = i; k < j; k++)    // split point
```

### 5. Coin change: initialize dp to INT_MAX, check before adding

```cpp
if (dp[j - coin] != INT_MAX)
    dp[j] = min(dp[j], dp[j - coin] + 1);
// Without this check: INT_MAX + 1 overflows to negative!
```

### 6. Stock problem III: the 4-variable trick

```cpp
buy1 = INT_MIN  // max profit after 1st buy (negative = spent money)
// Key: buy2 starts from sell1 profit, not from 0
```

### 7. Russian dolls: sort by height DESCENDING for same width

```cpp
sort(env.begin(), env.end(), [](auto &a, auto &b) {
    return a[0] == b[0] ? a[1] > b[1] : a[0] < b[0];
    //                    ^^^ height DESC for same width
});
```

### 8. Tabulation direction: fill dp in the direction of dependency

```
dp[i][j] depends on dp[i-1][...] → fill i from small to large (forward)
dp[i][j] depends on dp[i+1][...] → fill i from large to small (backward)
dp[i][j] = partition → fill by increasing interval length
```

### 9. Always check if dp can be modularized (MOD = 1e9+7)

```cpp
// For count problems, always take mod
dp[i][j] = (dp[i-1][j] + dp[i][j-1]) % MOD;
```

### 10. Burst balloons "last to burst" trick

```cpp
// WRONG: which to burst first? Hard because neighbors change
// CORRECT: which is last in range [l, r]? Left and right boundaries fixed
```

## 12. Final Revision Sheet

### Complete DP Decision Tree

```
Is there a linear structure?
  ├─ 1D array: House Robber, Climbing Stairs, Frog Jump
  ├─ 2D grid: Unique Paths, Min Path Sum, Triangle
  └─ Two strings: LCS, Edit Distance, Wildcard, Distinct Subseq

Is it about selection?
  ├─ 0/1 (take or skip): 0/1 Knapsack, Subset Sum, Partition
  └─ Unbounded (can repeat): Coin Change, Rod Cutting

Is it about a subsequence?
  ├─ LCS family
  └─ LIS family: patience sort for O(n log n)

Is it a stock problem?
  └─ Check number of transactions (1, 2, k, unlimited, fee, cooldown)

Is it a partition problem?
  └─ Matrix chain, Burst Balloons, Palindrome Partitioning

Is it on a tree?
  └─ Two states per node: dp[node][take], dp[node][skip]
```

### Templates at a Glance

```cpp
// 0/1 Knapsack (1D)
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)  // RIGHT TO LEFT
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);

// Unbounded Knapsack (1D)
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= W; j++)  // LEFT TO RIGHT
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);

// LCS
dp[i][j] = (s1[i-1]==s2[j-1]) ? 1+dp[i-1][j-1] : max(dp[i-1][j], dp[i][j-1]);

// Edit Distance
dp[i][j] = (s1[i-1]==s2[j-1]) ? dp[i-1][j-1] : 1+min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});

// LIS O(n^2)
for (int i=1; i<n; i++)
    for (int j=0; j<i; j++)
        if (arr[j]<arr[i]) dp[i] = max(dp[i], dp[j]+1);

// LIS O(n log n)
vector<int> tails;
for (int x : arr) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}
return tails.size();

// Partition DP template
for (int len = 2; len <= n; len++)
    for (int i = 1; i <= n-len+1; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++)
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i,k,j));
    }
```

### Complexity Table

| Pattern | Time | Space | Optimized Space |
|---------|------|-------|----------------|
| 1D DP (Climbing Stairs) | O(n) | O(n) | O(1) |
| Grid DP | O(m×n) | O(m×n) | O(n) |
| 0/1 Knapsack | O(n×W) | O(n×W) | O(W) |
| Unbounded Knapsack | O(n×W) | O(W) | O(W) |
| LCS | O(n×m) | O(n×m) | O(n) |
| Edit Distance | O(n×m) | O(n×m) | O(n) |

| LIS (patience) | O(n log n) | O(n) | — |
| Matrix Chain | O(n³) | O(n²) | — |
| Stock (k transactions) | O(n×k) | O(k) | — |
| Tree DP | O(V) | O(V) | — |
